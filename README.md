# 수완 종합게임

친구들과 방 코드(또는 초대 링크)로 모여서 하는 실시간 게임 사이트예요. 텍사스 홀덤 · 블랙잭 · 바카라를 할 수 있고, 보스를 깨는 **챌린지 모드**(게임마다 5단계)와 명예의 전당이 있어요.
방장은 대기실에서 AI 플레이어(쉬움·보통·어려움)를 추가할 수 있어요. AI는 서버 안에서 돌아가서 별도 비용이 없어요.

- 파일: `server.js`(서버), `index.html`(화면), `package.json`(실행 설정)
- 외부 패키지가 없어서 설치할 게 없어요. Node.js 18 이상이면 `npm start`로 실행돼요.

## Render에 올리기

1. GitHub에 새 저장소를 만들고 이 파일 3개를 올려요.
2. render.com에서 **New → Web Service**를 누르고 그 저장소를 골라요.
3. 설정값
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
4. 배포가 끝나면 나오는 `https://….onrender.com` 주소가 게임 사이트예요.

무료 플랜은 15분 동안 아무도 접속하지 않으면 잠들고, 다음 접속 때 깨어나는 데 1분 정도 걸려요. 서버가 잠들거나 다시 배포되면 진행 중이던 방은 사라져요.

## 챌린지 모드

- 첫 화면의 **챌린지 깨러가기** → 홀덤 / 블랙잭 / 바카라 중 고르고 단계를 골라요.
- 혼자 1:1로 하거나, 친구랑 같은 방에서 협동으로 보스를 깰 수 있어요. 앞 단계를 깨야 다음 단계가 열려요.
- 깬 기록은 서버의 `data/challenge.json`에 저장되고, 접속한 사람들 폰에도 서명된 사본이 남아요.
  무료 서버가 재시작돼서 파일이 지워져도 누군가 다시 접속하면 기록이 자동으로 되살아나요.
- (선택) Render 환경변수 `HOF_SECRET`에 아무 긴 문자열을 넣으면 기록 서명 키가 바뀌어요. 한 번 정하면 바꾸지 마세요 (바꾸면 예전 기록이 인정되지 않아요).
